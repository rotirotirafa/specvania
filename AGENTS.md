# AGENTS.md

This repository is built with Spec-Driven Development. Before doing anything, read and follow:

1. `.agent/execution-protocol.md` — how to execute rooms (tasks), stop rules, report format
2. `.agent/validation-gates.md` — what must be green before a room is cleared
3. `docs/domain.md` — vocabulary
4. `docs/conventions.md` — stack, layout, rules
5. `docs/spec.md` — the spec (decisions D1–D32 are binding)
6. `docs/tasks.md` — the rooms, in door order
7. `.agent/deviations.md` — accepted changes to the spec

Work on one room at a time, commit once per room, never push, and stop to ask when a stop rule applies.
